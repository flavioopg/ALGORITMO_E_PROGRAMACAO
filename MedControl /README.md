# 🏥 MedControl — Sistema de Gerenciamento de Atendimentos

**Sistema de cadastro, organização e gerenciamento de pacientes por classificação de prioridades.**

---

## 📌 Sobre o projeto

O **MedControl** é um sistema desenvolvido como parte de um **projeto acadêmico na UNIVAP (Universidade do Vale do Paraíba)**, durante os estudos de Lógica de Programação.

O objetivo é facilitar o gerenciamento de atendimentos, permitindo cadastrar pacientes, organizar filas e acompanhar os atendimentos realizados, aplicando conceitos fundamentais de programação na resolução de situações práticas.

---

## ⚙️ Funcionalidades

- 📝 **Cadastro de pacientes:** registro de informações pessoais e dados de atendimento.
- 📋 **Listagem:** exibição dos pacientes cadastrados.
- 🔎 **Consulta por código:** localização de pacientes no sistema.
- 🚦 **Organização da fila:** classificação dos pacientes por prioridade.
- 🏥 **Realização de atendimentos:** registro dos atendimentos realizados.
- ✅ **Pacientes atendidos:** consulta dos registros de atendimento.
- 📊 **Estatísticas:** apresentação de indicadores gerais.
- 🔁 **Busca recursiva:** localização de pacientes utilizando recursividade.

---

## 🚨 Classificação de prioridades

O sistema utiliza quatro níveis de prioridade:

| Nível | Classificação |
|:---:|:---|
| 🔴 **1** | Emergência |
| 🟠 **2** | Muito urgente |
| 🟡 **3** | Urgente |
| 🟢 **4** | Pouco urgente |

**Critérios de organização da fila:**

1. **Prioridade:** pacientes com maior urgência são posicionados primeiro.
2. **Idade:** em caso de mesma prioridade, pacientes mais velhos têm preferência.
3. **Ordem de cadastro:** se a prioridade e a idade forem iguais, prevalece quem foi cadastrado primeiro.

---

## 📊 Estatísticas

O sistema apresenta indicadores como:

- Total de pacientes cadastrados.
- Quantidade de pacientes aguardando e atendidos.
- Percentuais de atendimento.
- Média de idade e temperatura.
- Maior e menor idade.
- Quantidade de pacientes em prioridades elevadas.
